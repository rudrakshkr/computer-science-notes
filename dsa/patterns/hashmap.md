# Hash Map Pattern

## Use when

Need O(1) lookup.

Need to remember previous elements.

Need complement search.

---

## Common Problems

- Two Sum
- Happy Number
- Isomorphic Strings
- Valid Sudoku

---

## Time Complexity

Lookup: O(1)

Insert: O(1)

Delete: O(1)

---

## Red Flags

Nested loops.

Repeated searching.
