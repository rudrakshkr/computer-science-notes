# Low-Level Design (LLD) - Introduction

> Source: Hello Interview - Low-Level Design in a Hurry

---

## What is LLD?

Low-Level Design (LLD), also called **Object-Oriented Design (OOD)**, focuses on designing the **internal structure of a software system**.

Instead of thinking about services and scalability, LLD focuses on:

- Classes
- Objects
- Interfaces
- Relationships
- State
- Behavior

Example interview prompts:

- Design a Parking Lot
- Design Tic Tac Toe
- Design an Elevator
- Design a Coffee Machine

---

## What Interviewers Evaluate

- Problem analysis
- Object-oriented thinking
- Class design
- Separation of responsibilities
- Extensibility
- Communication

---

## LLD vs System Design

| Low-Level Design | System Design |
|------------------|---------------|
| Classes | Services |
| Objects | Servers |
| Methods | APIs |
| Relationships | Databases |
| State | Scalability |

---

## Key Takeaways

- Design **clean classes**, not distributed systems.
- Think in **responsibilities**, not implementation.
- Keep the design easy to extend.
- Explain your design decisions clearly.
